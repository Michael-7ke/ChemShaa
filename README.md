# ChemShaa — Web Landing Page

Our Static responsive implementation is inspired by public ChemShaa web visual:
- icon of ChemShaa is well intergrated
- "Stay Ready!" waiting-This is our lobby messaging
- 2:00 PM daily show
- yellow/green visual language
- phone mockup
- countdown of time 
- rules card
- animated floating particles and phone/card motion
- responsive mobile/tablet/desktop layouts
- optional browser notification button

Open `index.html` directly in a browser to load the landing page.

Point Note: the public website exposes the "Stay Ready!" / 2 PM visual, but the exact Android pre-show lobby screen and its private animation states are not exposed in the page source. This implementation therefore reproduces the publicly observable visual language rather than claiming a pixel-identical copy of an inaccessible app screen.
